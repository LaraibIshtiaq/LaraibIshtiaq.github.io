Projects

Agentic AI · RAG · In production

Enterprise HR AI Assistant

An AI assistant built into a company's internal employee management platform. Employees ask in plain English. It answers HR policy questions with cited sources and can look up or act on their own records.

  • An LLM router splits each message into intents and sends them to separate read and write agents for each HR area
  • Policy search combines keyword and FAISS vector retrieval, multi-query rewriting, reranking and parent-chunk expansion
  • Writes are safe: the assistant recaps the action and waits for a clear "yes", makes at most one write per turn, and every API call runs with the user's own permissions
  • Streams answers and shows a live reasoning panel in the web app, with chat history
  • Evaluated with RAGAS, retrieval-recall tests and routing regression suites
  • LangChain
  • Azure OpenAI
  • FastAPI
  • FAISS
  • RAGAS
  • React
